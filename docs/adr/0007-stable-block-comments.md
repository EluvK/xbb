# 0007: 基于稳定块标识的树状批注系统

## 决策背景与结论
知识库正文段落级批注决定基于稳定段落/块唯一标识 (Block UUID / 稳定锚点) 绑定评论树，废弃依赖“纯文本 AST 顺序 + 内容 Hash”的脆弱计算方式。核心原因在于纯文本 Hash 在正文内容发生任何微调时都会失效，导致评论大量沦为脱落的孤儿评论；基于稳定块标识使批注与正文段落强绑定，从根本上杜绝内容改动导致评论脱落，完全省去复杂的孤儿评论迁移机制。

## 被否决的备选方案 (Rejected Alternatives)
- **纯文本全文字符偏移量 (Text Offset)**: 前部任何插入或删除均会导致后续所有批注偏移量整体漂移错位。
- **模糊文本相似度比对 (Fuzzy Matching)**: 正文大幅重构时相似度阈值极难确定，存在严重误关联风险。
