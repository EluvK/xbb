# 0002: 剪贴板本地优先与绝对隐私同步

## 决策背景与结论
桌面平台后台全局钩子捕获的剪贴板内容极易包含密码、密钥、身份证号及私人凭据。决定捕获条目必须强制以 `localOnly = true` 仅持久化至本地 SQLite，绝对禁止任何自动化后台静默上云，只有用户在 UI 中手动多选并触发“确认同步”时才允许批量上传。核心原因在于个人隐私安全是桌面工具的根本底线，必须让用户对上云数据拥有 100% 的知情与掌控权。

## 被否决的备选方案 (Rejected Alternatives)
- **捕获即自动同步上云 (自动双写)**: 极大概率在用户不知情的情况下将密码、私钥或敏感隐私数据同步至服务端，带来灾难性合规与隐私风险。
- **本地正则过滤脱敏后自动上传**: 无法穷尽所有敏感内容模式，过滤规则存在漏判与误判，无法提供确定性的安全保证。
